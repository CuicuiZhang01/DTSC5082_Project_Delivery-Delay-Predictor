# Delivery Delay Predictor

## Project Overview
Predict delivery time and identify high-risk deliveries using machine learning.

## Dataset
This project uses the Amazon Delivery Dataset from Kaggle.

Dataset source: [Amazon Delivery Dataset](https://www.kaggle.com/datasets/sujalsuthar/amazon-delivery-dataset/data)

## Models
- Linear Regression
- Decision Tree
- Random Forest
- XGBoost
- SVR
- MLP

## Evaluation
- MAE
- RMSE
- R²

## Explainability
SHAP analysis is used to explain delivery-time predictions.

## Risk Prediction
- Low: ≤ 50th percentile
- Medium: 50th–75th percentile
- High: > 75th percentile
